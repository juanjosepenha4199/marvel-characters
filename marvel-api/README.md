# Marvel API

API en NestJS para el taller de personajes Marvel.

## Como correrlo

1. Levantar la base de datos desde la carpeta raiz del repo: `docker compose up -d`
2. Copiar `.env.example` a `.env`
3. Instalar y correr:

```bash
npm install
npm run start:dev
```

La API queda en http://localhost:3000
